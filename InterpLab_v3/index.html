КРАТКАЯ СПРАВКА

Два метода, одна задача

Метод Лагранжа

Многочлен строится как сумма произведений значений функции на базисные многочлены.

P(x) = Σ yᵢ · Lᵢ(x)

Lᵢ(x) = ∏ (x − xⱼ) / (xᵢ − xⱼ), где j ≠ i

Метод Ньютона

Многочлен записывается через разделённые разности и последовательно учитывает узлы интерполяции.

P(x) = f[x₀] + f[x₀,x₁](x−x₀) + …

Коэффициенты берутся из первой строки таблицы разделённых разностей.
