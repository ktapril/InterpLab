# InterpLab

**InterpLab** - веб-приложение для построения интерполяционных многочленов методами Лагранжа и Ньютона.

**Демонстрация:** https://ktapril.github.io/InterpLab/

## Возможности

- Ввод от 2 до 12 исходных точек с координатами X и Y.
- Построение интерполяционного многочлена методом Лагранжа.
- Построение интерполяционного многочлена методом Ньютона.
- Сравнение результатов двух методов.
- Отображение многочлена Лагранжа в раскрытом виде.
- Отображение многочлена Ньютона в нераскрытом и раскрытом виде.
- Пошаговое отображение вычислений.
- Построение таблицы разделённых разностей для метода Ньютона.
- Графическая визуализация интерполяционной функции и исходных точек.
- Проверка корректности введённых данных.
- Адаптивный интерфейс.

Также приложение доступно онлайн через GitHub Pages.

## Принцип работы

Пользователь вводит координаты исходных точек и выбирает один из трёх режимов работы: метод Лагранжа, метод Ньютона или сравнение обоих методов.

На основе введённых данных приложение строит интерполяционные многочлены. Результат метода Лагранжа отображается в раскрытом виде, а результат метода Ньютона - в нераскрытом и раскрытом видах.

Для метода Ньютона дополнительно формируется таблица разделённых разностей. Оба метода сопровождаются пошаговыми вычислениями. Полученный интерполяционный многочлен отображается на графике вместе с исходными точками.

## Назначение проекта

Проект разработан в учебных целях для изучения методов численной интерполяции Лагранжа и Ньютона, построения интерполяционных многочленов и сравнения результатов их применения.
