# InterpLab

**InterpLab** - веб-приложение для численного интерполирования функций методами Лагранжа и Ньютона.

https://ktapril.github.io/InterpLab/

## Возможности

- Интерполяция методом Лагранжа.
- Интерполяция методом Ньютона.
- Сравнение двух методов.
- Пошаговое отображение вычислений.
- Таблица разделённых разностей.
- Графическая визуализация интерполяционного многочлена.
- Проверка корректности введённых данных.
- Адаптивный интерфейс.

## Используемые технологии

- HTML5
- CSS3
- JavaScript (ES6)
- MathJax
- SVG

## Запуск приложения

1. Склонировать репозиторий:
   ```bash
   git clone https://github.com/ktapril/InterpLab.git
   ```
2. Открыть папку проекта в Visual Studio Code.
3. Запустить файл `index.html` с помощью расширения Live Server.

## Принцип работы

Пользователь вводит набор исходных точек с координатами X и Y, выбирает метод интерполяции и задаёт значение X, для которого необходимо вычислить значение функции.

Приложение выполняет вычисления, отображает подробные этапы решения и строит график полученного интерполяционного многочлена.

## Назначение проекта

Проект разработан в учебных целях для изучения и сравнения методов численной интерполяции Лагранжа и Ньютона.
